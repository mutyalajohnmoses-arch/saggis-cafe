# SAGGI'S CAFE

Premium five-page cafe website built from scratch with React + TypeScript, Framer Motion and a responsive custom visual system.

## Pages
- Home
- Menu
- Gallery
- About
- Contact

## Client integrations

## Content safety
The site deliberately avoids inventing menu items, prices, opening hours, awards, reviews, founder information or exact address details that have not been confirmed. Replace the clearly marked content placeholders with the cafe's approved information and supplied media.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
